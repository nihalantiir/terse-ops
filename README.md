# Terse Ops

Claude Code plugin. Short answers. High-level orchestration. Safe edits.

Opus (or your top model) plans and delegates. Smaller models do the work.
A damage harness limits blast radius. Failures are reported, not researched forever.

Not related to TERSE state language, TerseAI workflows, or be-terse hooks.
This is an original ops style: concise output + orchestrator role + safety rules.

## Install

```
text
/plugin marketplace add YOUR_GITHUB_USER/terse-ops
/plugin install terse-ops@terse-ops
```
