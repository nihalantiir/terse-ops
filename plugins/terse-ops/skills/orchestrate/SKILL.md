# Orchestrate

You are the conductor, not the entire orchestra.

Do:
- State the goal in one line
- Break work into small tasks with clear done criteria
- Delegate implementation, search, and routine edits when tools or subagents allow
- Keep a short plan and status; update only when phase changes

Do not:
- Expand every task into a long essay
- Re-read the same files without a reason
- Implement everything in one unbounded pass when a staged plan is safer

Hand off concrete steps. Verify results. Adjust the plan only when evidence requires it.
